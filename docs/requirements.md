# Hotel Reservation System — Requirements

## 1. Introduction

This document defines the initial functional requirements of the Hotel Reservation System. The requirements will be refined as the project progresses.

## 2. Functional Requirements

### Room Availability

**FR-AV-01:** The system shall allow guests to search for available room types using check-in date, check-out date, and number of guests.

**FR-AV-02:** The system shall display room types that have sufficient capacity and availability for the requested stay.

### Reservations

**FR-RS-01:** The system shall allow guests to create reservations for a room type without assigning a specific physical room.

**FR-RS-02:** The system shall allow guests to view, modify, and cancel their own reservations.

**FR-RS-03:** The system shall allow authorized receptionists to manage guest reservations.

**FR-RS-04:** The system shall prevent overbooking when reservations overlap and the available capacity of a room type has been reached.

### Check-in

**FR-CI-01:** The system shall allow receptionists to assign a suitable available physical room to a reservation during check-in.

## 3. Pending Requirements

The following details will be defined later:

- Guest authentication and account management.
- Cancellation and refund policies.
- Detailed billing and tax calculations.
- Room assignment rules and unexpected room unavailability.

This is an initial draft. Additional functional and non-functional requirements will be added during requirements engineering.

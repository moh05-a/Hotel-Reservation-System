# Increment 1 — AI-Assisted Design Record

**Version:** v0.1.0-design  
**Increment:** Foundation and Staff Authentication

## 1. Design Task

Prepare the authentication and authorization design for the Hotel Reservation System according to FR-AU-01–03, NFR-03, and NFR-06.

The system must support staff login, role-based access control, and logout. Guests must not require website accounts.

## 2. AI Assistance

ChatGPT was used to help prepare:

- Staff authentication and authorization documentation.
- Role-Based Access Control (RBAC) matrix.
- StaffUser and StaffSession database design.
- Authentication Sequence Diagram using PlantUML.
- Proposed API endpoints and security rules.

The design uses React, FastAPI, PostgreSQL, and server-side sessions.

## 3. Design Decisions

- Only hotel staff have login accounts.
- Staff roles are Hotel Manager, Receptionist, and Housekeeping Staff.
- The backend enforces staff permissions.
- Passwords are stored using secure hashes.
- Server-side sessions allow logout to invalidate access.
- Guests can use public booking features without staff authentication.
